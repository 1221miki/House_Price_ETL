# Data Directory

This directory stores the US Residential Properties and Sale Events Parquet datasets:
- `properties-00000-of-00001.parquet` (~200 MB, 3,306,420 records)
- `sale_events-00000-of-00001.parquet` (~161 MB, 3,703,094 records)

*Note: The raw `.parquet` data files are excluded from Git commits via `.gitignore` because they exceed GitHub's 100 MB file size limit.*
